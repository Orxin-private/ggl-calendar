# Google Calendar 커스터마이저 v1.2.8

## 업데이트 내용

- **시간 일정 앞 표시 수정**: 원형 점의 구현이 `background-color`인 경우뿐 아니라 `0×0 요소 + 두꺼운 border-color`인 경우도 탐지합니다. 기존 점 색상을 유지하면서 사각형·마름모·삼각형·별·하트·고리·반짝이 등으로 변경합니다.
- **::before CSS 점 지원 개선**: 캘린더가 의사요소로 점을 렌더링하는 경우의 CSS 선택자를 수정했습니다.
- **우클릭 메뉴 3열**: `테두리 효과 / 일정 카드 모양 / 시간 일정 앞 표시`를 한 번에 나란히 표시합니다. 일반적인 데스크톱 브라우저 높이에서는 세로 스크롤 없이 선택할 수 있으며, 작은 창에서는 화면 안에서 스크롤됩니다.
- 기존 주말 강조, 투명도, 다크 모드, 오늘 날짜 강조, 애니메이션 테두리 등은 유지합니다. Google Calendar API 사용하지 않습니다.

## 기존 설치에 적용

1. ZIP 파일을 압축 해제합니다.
2. `Repair-Installed.cmd`를 실행합니다.
3. Chrome/Edge에 기존에 등록된 확장프로그램 폴더를 선택하여 덮어씁니다.
4. `chrome://extensions`에서 확장프로그램을 다시 로드하고 버전 `1.2.8`을 확인합니다.
5. 캘린더 탭에서 `Ctrl + Shift + R`을 누릅니다.

## 참고

Google Calendar의 HTML은 공개 인터페이스가 아닙니다. 실제 로그인된 화면의 일정 종류·화면 모드에 따라 아직 지원되지 않는 점 유형이 있을 수 있습니다. 업데이트 설치와 테스트는 별개이며 Google 계정 화면에서의 동작은 검증되지 않았습니다. 콘솔의 `ObjectMultiplex`, `MaxListenersExceededWarning`은 본 확장프로그램에서 직접 발생시키는 메시지가 아닙니다.
